1.2  Architecture  Principles  
Principle Implementation 
AWS-native  only  
Bedrock  for  AI,  SES  for  email,  Cognito  for  auth,  CloudFront  for  CDN.  No  Stripe,  SendGrid,  or  OpenAI  dependencies.  
Serverless-first  
Lambda  for  AI  and  ingestion.  Next.js  API  routes  for  forms.  No  always-on  servers  beyond  RDS.  
Least-privilege  IAM  
Every  Lambda  has  its  own  role  scoped  to  exactly  what  it  needs.  Amplify  has  zero  direct  database  access.  
HIPAA-ready  
No  PHI  collected  today.  Schema  and  VPC  structured  so  a  BAA  upgrade  requires  no  rebuild.  
Local-first  development  
The  entire  website  and  chatbot  are  built  and  validated  locally  before  a  single  AWS  deployment.  This  eliminates  wasted  cloud  spend  on  broken  builds.  
Beginner-friendly  
Step-by-step  roadmap  in  Section  12.  Every  AWS  action  is  a  specific  console  or  CLI  command.  Nothing  is  vague.  
Scale  to  thousands  
CloudFront  CDN  for  static  pages,  Lambda  concurrency  controls,  HNSW  vector  search,  RDS  read  replica  path  defined.

6.  RAG  Chatbot  Implementation  
Chatbot  Behavioral  Contract 1.   The  chatbot  NEVER  collects  any  form  data:  no  names,  no  phone  numbers,  no  email  addresses,  no  health  information.  2.   The  chatbot  ONLY  guides  users.  It  answers  PHM  questions,  describes  programs,  and  explains  processes.  3.   Every  informational  response  ends  with  one  of  two  CTAs:  Refer  a  Patient  (links  to  /refer)  or  Request  a  Consultation  (links  to  /contact).  4.   On  any  medical  emergency  keyword  (chest  pain,  can't  breathe,  unconscious,  call  911,  etc.),  the  chatbot  responds  ONLY  with  'Please  call  911  immediately.'  No  other  text.  5.   On  any  referral  intent  ('I  want  to  refer',  'how  do  I  submit  a  patient',  'enroll  my  patient'),  the  chatbot  says  'Please  use  our  referral  form'  and  shows  the  Refer  a  Patient  CTA.  It  does  not  take  down  any  information.  6.   The  chatbot  never  pretends  to  be  a  doctor,  never  gives  diagnoses,  and  never  contradicts  a  physician.
