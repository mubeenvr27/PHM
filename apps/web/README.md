# PHM Web Service

This directory contains the **Next.js 14 App Router** frontend and the lightweight **Next.js API routes**.

## Responsibilities
- Rendering the patient information hub and referral forms.
- Handling synchronous form submissions (`/api/refer`, `/api/contact`).
- Triggering AWS SES emails for submission confirmations.
- Managing the Admin Dashboard for staff interaction.
- Client-side analytics integration (GA4).
